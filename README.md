\# 📊 SQL Business Sales Analysis



\## 📌 Project Overview



This project analyzes e-commerce sales data using MySQL and SQL.



The goal is to identify business insights related to revenue, profit, products, customers, categories, regions, and monthly sales performance.



\## 🎯 Objectives



\- Analyze total revenue and profit

\- Identify top-selling products

\- Analyze sales by category

\- Compare regional performance

\- Identify top customers

\- Calculate Average Order Value

\- Analyze monthly revenue

\- Perform product and region ranking

\- Calculate month-over-month revenue changes
